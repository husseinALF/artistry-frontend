# README - Frontend (React)

## Online Gallery Platform - Frontend

This is the frontend part of Artistry, a web application built with React that allows users to:

- Browse and interact with other users' images.
- Upload their own images.

---

## Installation and Setup

### Prerequisites:

- **Node.js** (v14 or later)
- **npm** (Node Package Manager)

### Installation Steps:

1. Navigate to the frontend directory:

   ```bash
   cd artistry-frontend
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

The frontend application will run on [http://localhost:5173](http://localhost:5173).

## Design Guidelines

### Color Scheme:

- **Primary Color:** #041122 (Dark Navy Blue)
- **Secondary Color:** #259073 (Turquoise Green)
- **Tertiary Color:** #7fda89 (Light Green)
- **Accent Color:** #e6f99d (Light Yellow)

### Fonts:

- **Main Font:** apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;

### Typography:

- **Heading Sizes:**
  - H1: 1.8rem
  - H2: 1.5rem
  - H3: 1.3rem
- **Body Text:** 1rem

### Design Principles:

- Minimalist design
- Clear typographic hierarchy
- Rounded corners and soft shadows for a modern feel
- Responsive design for all screen sizes
